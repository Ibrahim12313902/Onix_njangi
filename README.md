# ONIX Njangi Management System

A web-based management system designed to simplify the administration of Njangi groups by organizing members, contributions, savings, payouts, and group activities.

## About the Project

ONIX Njangi aims to make Njangi group management more organized, accessible, and efficient by bringing essential management functions together in one application.

This project was developed as a software engineering project to apply web development and database management skills to a practical problem.

## Features

- **Member Management:** Organize and manage group members.
- **Contribution Management:** Record and monitor member contributions.
- **Savings Management:** Maintain savings records.
- **Payout Management:** Manage payout cycles and payout records.
- **Administrator Dashboard:** Provide an overview of group activities.
- **Member Portal:** Give members access to relevant information.
- **Announcements and Group Chat:** Support group communication.
- **Reports:** Help administrators review group records.
- **System Settings:** Configure application settings.

## Getting Started

### Prerequisites

To run the complete application locally, you will need:

- A local PHP development environment, such as XAMPP or WampServer.
- PHP.
- MySQL or MariaDB.
- A web browser.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/ibrahim12313902/Onix_njangi.git
   ```

2. Move the project into your local web server's document directory.

3. Start Apache and MySQL.

4. Create a MySQL database for the application.

5. Import the appropriate database schema, if one is provided.

6. Configure the database connection using your local environment settings.

7. Open the application through your local web server.

**Important:** The exact database name, configuration settings, and startup URL depend on the application's current configuration.
